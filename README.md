# BRZ Tecnologia Landing Page

Landing page em React para soluções de tecnologia, com foco em discadores para call center: preditivo, power e preview.

## Desenvolvimento

```bash
yarn
yarn dev
```

## Build

```bash
yarn build
```

## Publicação no GitHub Pages

O deploy é feito automaticamente pelo workflow `.github/workflows/deploy.yml` sempre que houver push na branch `main`.

No GitHub, configure o Pages em:

`Settings > Pages > Build and deployment > Source > GitHub Actions`
